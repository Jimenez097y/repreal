# RepReal

App web de entrenamiento en casa, sin equipo, pensada para empezar desde cero.

- Rutinas guiadas con temporizador, voz y animación de cada ejercicio
- Modo bajo impacto (sin saltos) y plan progresivo de 4 semanas
- Conteo de repeticiones con la cámara (detección de postura con MediaPipe)
- Grabación de la sesión con contador y marca de agua, lista para redes
- Registro de peso, caminatas, fotos de progreso y comparación antes/después

Todo se guarda en el celular de cada usuario. No hay servidor ni cuentas.

**Usar:** abre la página de GitHub Pages en Safari (iPhone) o Chrome (Android) y permite la cámara.
